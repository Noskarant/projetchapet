# Tutoriel guidé MANUFEO

Le parcours entreprise obligatoire reste inchangé. Une fois ce profil complété, le tutoriel remplace les anciennes diapositives par un guidage contextuel sur les vrais éléments visibles de l'application.

- parcours distinct desktop/mobile ;
- spotlight sur la cible réelle avec progression ;
- navigation Suivant / Précédent / Passer ;
- ouverture automatique des sections lorsque cela est possible ;
- fallback centré si une cible n'est pas présente dans le DOM ;
- mémorisation de la fin du tutoriel via le profil entreprise existant ;
- événement `manufeo:replay-tour` disponible pour un futur bouton « Revoir le tutoriel » dans les paramètres.
