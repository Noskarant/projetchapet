# Socle de test artisan Rapiddos

Ce lot prépare un test réel sans toucher à l’authentification ni à la landing page.

- démarrage mobile vierge avec sauvegarde locale préalable ;
- dictée dont la transcription brute est masquée par défaut ;
- suggestions contextuelles de postes oubliés sans prix, quantité ni TVA inventés ;
- recherche d’entreprise par SIRET via l’API publique Recherche d’Entreprises ;
- profil entreprise : identité, logo, exercice comptable et texte d’e-mail ;
- statut de connexion Resend visible sans exposer la clé ;
- bouton d’exercice comptable desktop rendu fonctionnel ;
- personnalisation des e-mails envoyés avec l’identité de l’artisan.

La facturation électronique, les moteurs métiers, le cycle devis/facture et les données de rentabilité existants ne sont pas modifiés par ce lot.
